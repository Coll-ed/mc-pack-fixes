# 清理管家

Agent 项目文件清理的报告与自检记录，来自 `D:\AI\AI工具箱\_janitor`。

## 口径（原文）

- 只读取证 + 向属主会话派单；管家自身**不代替属主删任何文件**
- 删除动作一律由目录属主会话自行裁定并执行（信箱不支持 AI 间下达删除命令）

## 内容

- `清理报告-*.md` — 每轮清理的取证与结论
- `_selfclean-*.log` — 自清理日志（附件、删除、归档）
- `lib/` — 清理逻辑
- `attachments-audit/` — 附件审计

这是「AI 之间怎么安全地清理文件」的一次完整实践：先取证、再派单、由属主执行。
